# Software Requirements Specification (SRS) - LostLink

**English** | [Tiếng Việt](srs.vi.md)

## 1. Introduction

LostLink is a web platform that helps people in Ho Chi Minh City find and return lost items: it automatically suggests matches between Lost and Found posts, verifies ownership before a handover and keeps both sides' contact details private. This document lists the functional, non-functional and system requirements and is the shared reference for design, implementation, testing and code review.

### 1.1. User roles

Moderator and Admin both inherit the User permissions.

| Role          | Description                          | Requirement groups |
| ------------- | ------------------------------------ | ------------------ |
| **Guest**     | Visitor who is not signed in         | G01-G05            |
| **User**      | Signed-in user with a verified email | G01, G02, U01-U09  |
| **Moderator** | Moderates content                    | U01-U09, M01-M05   |
| **Admin**     | System administrator                 | U01-U09, A01-A08   |

### 1.2. Glossary

| Term                  | Meaning                                                                                         |
| --------------------- | ----------------------------------------------------------------------------------------------- |
| Lost / Found post     | The two post types. The matcher always pairs one Lost post with one Found post.                 |
| Match suggestion      | A pair of opposite posts scored by the system and sent to both sides, with a score and reasons. |
| Verification question | A multiple-choice question the finder sets on a Found post. It can be answered only once.       |
| Contact request       | A single intro message to the post owner. A conversation opens only after it is accepted.       |
| Watch area            | An area (center and radius) a user follows to be notified about new posts.                      |
| Reputation            | Points earned from successful handovers and reviews, used for the leaderboard and badges.       |

## 2. Functional requirements

### 2.1. Guest

A Guest is a visitor who is not signed in.

| Feature                                        | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **G01** - Browse and search posts              | • **Latest posts:** show only posts approved by a Moderator and not hidden. Each card shows the cover image, Lost/Found label, author, category, title, post time, short description, place and area, time of loss/find, and like, comment and view counts. Newest first by default. Clicking a card opens the post detail.<br>• **Filter and search:** filter by post type, category, area and time range (default: all categories, last 7 days). Keyword search over item name, description, area and place.<br>• **Hot posts:** sorted by `hotScore = views + likes × 20`, with the same filters as the home page.<br>• **Post detail:** images, post type, category, title, description, attributes, post time, time of loss/find, place, author with reputation and number of returns, like/comment/view counts and the comment list. Each open counts as one view.<br>• When a Guest clicks Like, Save, Follow, Comment, "This is mine", "I have this item" or Report, the system goes to Sign in and returns to the same page afterwards. |
| **G02** - View leaderboard and community stats | • **Leaderboard:** the quarterly "Kind people" board, ranked by reputation, with rank, username, number of returns and points. Guests see it only in the home page's right column. Clicking a person asks them to sign in.<br>• **Community stats:** anonymous totals: posts created, items returned, match success rate and average time to return.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **G03** - Register                             | • **Username:** 3-30 characters, only unaccented letters, digits, dots and underscores, unique.<br>• **Email:** valid format, lowercased automatically. If the email is already verified on another account, say it is already registered.<br>• **Password:** 8-72 ASCII characters, no accents or spaces, with at least 1 lowercase letter, 1 uppercase letter, 1 digit and 1 special character.<br>• **Email opt-in:** optional, checked by default. **Accept terms:** must be checked before submitting.<br>• If the input is valid, create an unverified account and email a 6-digit code.<br>• **Email verification:** 6-digit OTP, valid for 10 minutes, at most 5 wrong attempts (after that a new code is required). Resending a code invalidates the old one. A successful verification signs the user in.                                                                                                                                                                                                                              |
| **G04** - Sign in                              | • **Email and password:** wrong credentials show only the generic "Email or password is incorrect". Unverified accounts go to the verification screen (enter the code or resend it). Locked accounts cannot sign in.<br>• **Google:** authenticate with a Google ID token. Accounts already linked to Google sign in directly. Otherwise create a new account: the username comes from the part of the email before @ (with a number appended if taken), and the email counts as verified.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **G05** - Recover password                     | • **Forgot password:** the user enters an email and receives a reset link valid for 10 minutes.<br>• **Reset password:** the link must be valid and unexpired, and the new password follows the G03 rules. A successful reset signs the account out on every device.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |

### 2.2. User

A User is signed in with a verified email and can also use the Guest features G01 and G02.

| Feature                             | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ----------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **U01** - Sign out                  | End the current session. Old tokens are revoked and cannot be reused.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **U02** - Manage profile            | • **View profile:** username, avatar, bio, badges, reputation, own posts, thanks and reviews from others.<br>• **Update profile:** change avatar, bio and usual areas.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **U03** - Manage account            | • **Change password:** enter the current and new password. Old sessions are revoked afterwards.<br>• **Change email:** the new email must be unused and verified with an OTP before it replaces the old one.<br>• **Delete account:** requires confirmation. All posts and messages are deleted and cannot be restored 3 days after confirming.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **U04** - Community connections     | • **View another user's profile:** name, badges, bio, reputation, posts (filter All / Lost / Found) and the "What others say" section.<br>• **Follow / unfollow:** get notified when that user posts.<br>• **Block / unblock:** hide the blocked user's posts and lock conversations with them. Unblocking shows the posts again and unlocks conversations.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| **U05** - Manage own posts          | • **Create a Lost / Found post:**<br>&emsp;◦ Classification: post type, category, attributes.<br>&emsp;◦ Content: required title (max 120 characters), description up to 1,000 characters, optional images (JPG, PNG or WEBP, up to 9 images, max 5 MB each, the first one is the cover).<br>&emsp;◦ Time: date of loss/find is required and cannot be in the future. Approximate times ("This morning", "Last night") and a time-of-day range are allowed.<br>&emsp;◦ Location: GPS, drag a pin, type an address or pick a street segment, plus a required district.<br>&emsp;◦ Multiple-choice verification question: Found posts only, optional.<br>&emsp;◦ Review before posting: show all content step by step, with the option to go back and edit any step.<br>&emsp;◦ New posts start as Pending. Restricted accounts cannot post.<br>• **Save draft:** keep unfinished content. Reopening the compose form shows the draft and resumes from the unfinished step.<br>• **Edit post:** own posts only, and not when Contacted, Returned or Closed. An edited post returns to Pending and is hidden until approved again.<br>• **Delete post:** own posts only. Warn first if the post has an active match or conversation.<br>• **Close / mark as Returned:** close the post when the item was not found or is no longer needed (Closed), or mark it Returned. Every state change is recorded in the history. Closed posts are hidden from public lists (Home, Hot posts, Profile).                                                                                                                                                                                                                                                                                                                                                                                         |
| **U06** - Interact with posts       | • **Comment:** up to 500 characters, edit/delete own comments only, at least 15 seconds between comments.<br>• **Like / unlike:** one like per user per post. Likes feed the hot score.<br>• **Save:** keep the post in the Saved list.<br>• **Follow post:** get notified when the post changes state or gets a new comment.<br>• **Report:**<br>&emsp;◦ Report a post (from Post detail) for: asking for money, spam, fake post, other. Report a user (from a conversation) for: asking for money, spam, harassment, false claim, other.<br>&emsp;◦ "Other" requires a description. Description up to 1,000 characters, optional screenshots (up to 3 JPG, PNG or WEBP images, max 5 MB each).<br>&emsp;◦ Each user can report a post or a user only once. Reporters stay anonymous, receive the outcome and are rate limited.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| **U07** - Matching and verification | • **Match suggestions:** a "Could this be yours?" list. Each suggestion shows the opposite post's card, a match score and reasons ("~800 m away", "1 day apart"). The owner clicks "Yes, it's mine" to go to verification or send a contact request. The finder clicks "I have this item" to send a contact request. "Not mine" marks the suggestion as rejected.<br>• **Claim from a post:** Found posts have a "This is mine" button, Lost posts have an "I have this item" button. Clicking it starts the verification/contact flow, with rate limiting.<br>• **Answer the verification question:** applies when a Found post has a question, and it can be answered only once. A correct answer opens a conversation and moves the post to Contacted. A wrong answer fails verification and cannot be retried for that post (prevents false claims).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **U08** - Contact and handover      | • **Send a contact request:** applies when the finder skipped the verification question (the Found post has none), or when a finder clicks "I have this item" on a Lost post. The sender gets one intro message and can continue only after it is accepted.<br>• **Review contact requests:** the post owner reads the intro and either Accepts (opens a conversation, the post moves to Contacted) or Declines.<br>• **Messaging:** available only after a correct verification or an accepted contact request. The conversation list is searchable, each conversation is tied to its post, and users can send text, take photos or send images. Users can also open a conversation with a Moderator for support (complaints, stalled handovers, incidents…).<br>• **Confirm handover:** when both sides confirm, the post moves to Returned and the returner gains reputation. If a conversation stays open past the deadline set in A05 without either side confirming Returned or closing it, the system sends a reminder email (HT05).<br>• **Close and reopen a conversation:**<br>&emsp;◦ Either side can close a conversation when the item does not match. If the post has no other open conversation it goes back to Searching, otherwise only that conversation closes.<br>&emsp;◦ A conversation you closed moves to "Closed": new messages from the other side are still stored, but send no notification and do not count as unread.<br>&emsp;◦ The other side sees a "not a match" note and can still message, but cannot confirm the handover.<br>&emsp;◦ The closer can reopen it at any time to see all messages and continue. If the post is still Searching it moves back to Contacted.<br>• **Review and thank:** shown once the post is Returned. Pick a 5-level rating, the other person's strengths and write a thank-you note. Reviews affect reputation. |
| **U09** - Notifications             | • **Notification settings:** toggle email, toggle push notifications, choose which notification types to receive. With email off, the 12-hour reminder email is not sent.<br>• **Notification center:** notifications about matches, comments, post approval/rejection, report outcomes and new posts in watch areas. Filter by type, mark as read. Important notifications are also emailed when enabled.<br>• **Watch areas:** pick a center on the map and a radius, add/remove/toggle each area. New posts inside an area trigger a notification.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |

## 3. Non-functional requirements

| Code | Requirement                | Description                                                                                                                                                                                                                                                                                          |
| ---- | -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| NF01 | Hide contact details       | Email and contact details are never public. Intro messages cannot contain phone numbers or addresses. Reported users never learn who reported them.                                                                                                                                                  |
| NF02 | Password and code storage  | Passwords are hashed with bcrypt. OTPs, password reset tokens and verification answers are stored only as hashes.                                                                                                                                                                                    |
| NF03 | Session management         | JWT: 15-minute access token, 7-day refresh token, refreshed automatically. Signing out, changing or resetting the password revokes every old token.                                                                                                                                                  |
| NF04 | Authorization              | Permissions are checked on the server by role and ownership. Guests can read only public data and are asked to sign in when using member features.                                                                                                                                                   |
| NF05 | Abuse and fraud prevention | Auth API 20 requests/15 minutes/IP, general API 300 requests/15 minutes. At most 5 wrong OTP attempts. Verification questions are answered once.                                                                                                                                                     |
| NF06 | Backup and recovery        | Daily automatic database backup at 04:00, kept for 6 months. Admins can restore data after an incident.                                                                                                                                                                                              |
| NF07 | Error handling             | Errors share one response format. 5xx errors do not leak internal details. Failures in external services (email) do not break the main action.                                                                                                                                                       |
| NF08 | Integrity and availability | Every post state change is recorded in its history. At least 99% uptime per month.                                                                                                                                                                                                                   |
| NF09 | Response time              | Page load, filtering and search within 2 seconds. Save actions within 3 seconds (excluding image upload). Match suggestions within 1 minute of approval, if matching posts exist.                                                                                                                    |
| NF10 | Load capacity              | At least 100 concurrent users while still meeting NF09. Lists are paginated and use geospatial indexes.                                                                                                                                                                                              |
| NF11 | Usability                  | Vietnamese UI with clear error messages. Desktop first, responsive on mobile.                                                                                                                                                                                                                        |
| NF12 | External integrations      | Google Identity (Google sign-in), Cloudinary (image storage: up to 9 images per post, max 5 MB each), SMTP Gmail (email delivery), and a map and geocoding service.                                                                                                                                  |
| NF13 | Configurable parameters    | Radius, time window, matching parameters, report thresholds and reminder delays are editable from the Admin screens without code changes.                                                                                                                                                            |
| NF14 | System logs                | Server error logs. Read-only audit log of Moderator/Admin actions (who, what, when). Logs never contain passwords, OTPs or tokens.                                                                                                                                                                   |
| NF15 | Personal data and licenses | Comply with the Personal Data Protection Law No. 91/2025/QH15 and Decree 356/2025/ND-CP: send email only with consent, let users delete their data. Use only open-source libraries whose licenses allow free use (MIT, BSD, Apache 2.0). Follow the terms of Google, Cloudinary and the map service. |

## 4. System requirements

| Code | Requirement                     | Description                                                                                                                                                                                                                                                                        |
| ---- | ------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| HT01 | Data storage and processing     | Add, update, delete and search data in the database. What each role can see depends on the role (Guests see only public data).                                                                                                                                                     |
| HT02 | Two-way automatic matching      | When a post is approved (moves to Searching), the system looks for opposite posts (Lost ↔ Found) among Searching or Contacted posts: hard filters on radius and time window, then scoring. The algorithm is described in [matching-algorithm.md](../design/matching-algorithm.md). |
| HT03 | Automatic emails                | Send verification OTPs, password reset links and important notifications to users who opted in to email.                                                                                                                                                                           |
| HT04 | Contact reminder                | If the owner has been verified but the finder has not been online within the contact reminder delay (default 12 hours, set in A05), email the finder "someone needs to contact you about post …" (if the finder opted in to email).                                                |
| HT05 | Handover reminder               | If a conversation stays open past the reminder deadline (set in A05) without either side confirming Returned or closing it, email both sides a reminder (if they opted in to email).                                                                                               |
| HT06 | Auto-restrict reported accounts | If an account is reported by 3 different people within 7 days, flag it and notify Moderators. With 5 or more reporters within 7 days, temporarily block sensitive actions (posting, sending contact requests) until a Moderator handles it.                                        |
| HT07 | Reputation and badges           | Add reputation for successful handovers and from reviews. Award badges automatically when their conditions are met.                                                                                                                                                                |
| HT08 | Leaderboard and stats           | Compute the quarterly leaderboard and community stats from user, post and review data.                                                                                                                                                                                             |
| HT09 | Watch area alerts               | When a newly approved post falls inside an area a user registered, notify that user.                                                                                                                                                                                               |
| HT10 | Post-handover privacy           | Posts are hidden automatically 7 days after moving to Returned.                                                                                                                                                                                                                    |
